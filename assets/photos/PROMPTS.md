# SkillPal card photographs

Generated with the built-in imagegen tool. These are fictional learning scenes, not photographs of the demo members. Six category photographs are reused across twelve cards.

Original PNG files are preserved in result/card-photo-originals locally. Published WebP files retain the original dimensions and use quality 82 encoding; no crop or scene edits were applied.

## coding.webp

Use case: photorealistic-natural. Asset type: cover photograph for a Chinese skills exchange demo SkillPal. Landscape 3:2 composition.
