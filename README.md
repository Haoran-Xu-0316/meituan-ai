# SkillPal

你会的，正好是我想学的。

线上技能互换产品演示，采用美团黄色系。公开站点：https://meituan-ai.pages.dev/

## 使用方式

进入发现页浏览伙伴；发布自己的能教与想学；查看双向匹配；发送邀请后使用明确标注的演示控制接受或拒绝；分别完成两节45分钟课程，最后提交评价。

首页提供可展开的体验指引。每位伙伴的实操样例提供具体材料、练习题、参考结果与可下载讲义；编程伙伴还提供完整可运行文件。12位伙伴均有独立的45分钟教学安排、课前准备、课后练习、成果说明和明确标注的示例反馈。交换详情可查看伙伴的准备清单。

默认身份为小麦，能教摄影、想学Python。林予安为共同时间匹配；唐知远为需要协商时间的匹配。修改学习技能会重新计算匹配结果。我的页面可管理发布、收藏、资料与重置演示。

这是纯前端演示：人物与评价示例均有标识；没有真实注册、消息投递、会议、支付、认证或跨设备同步。课程完成按钮用于模拟履约。资料、草稿、收藏与交换记录保存在当前浏览器。不要填写敏感个人资料。

## 项目组织

- `index.html`：网页入口与品牌元数据。
- `assets/style.css`：设计令牌、组件样式与手机适配。
- `src/app.mjs`：页面、路由与事件处理。
- `src/model.mjs`：匹配、日期校验、状态机与持久化。
- `data/seed.mjs`：技能目录、示例伙伴与初始身份。
- `data/workshops.mjs`：12份实操样例、原始数据、参考代码、练习题和下载材料。
- `tests/`：独立业务规则与优化回归测试，使用Node内置测试模块。
- `PRODUCT.md`、`DESIGN.md`：产品边界与视觉规范。
- `result/`：本地验收记录，忽略提交。

## 本地预览与校验

在项目根目录通过IDE或静态HTTP服务打开index.html。ES模块需通过HTTP访问，不能直接双击file地址。没有依赖安装或构建步骤。测试文件可由支持Node测试的编辑器直接运行。

验收包含双向匹配、时间窗口与冲突、邀请去重、暂停发布、两节课程状态流转、取消记录保留、一次评价、本地存储恢复。浏览器需额外验收表单、收藏、搜索、手机布局和公开部署。

## 内容更新

伙伴与技能示例统一维护在data/seed.mjs。业务规则位于src/model.mjs，页面文案与结构位于src/app.mjs。课程内容集中在data/seed.mjs的LESSON_CONTENT中维护，每位伙伴的三个教学环节总计45分钟。发布草稿保留当前步骤；损坏草稿单独清除，已发布资料与交换记录继续保留。修改存储结构时更新版本号，并保持明确的恢复提示。

所有开发、测试和检查记录均限定在桌面meituan-ai仓库。每个文件单独提交英文说明，不提交result、依赖目录或无关文件。

## Cloudflare部署

项目meituan-ai已经连接本仓库main分支。框架为None，无构建命令，输出目录为`.`。推送后等待Pages部署成功，并检查公开页面，而不是只以Git推送成功为准。Hash路由支持直接打开与刷新。

部署前检查远程版本，按文件提交；部署失败保留上一成功版本，在Cloudflare中回滚。未来若改成真实多人平台，需要另行实现服务端身份认证、数据库、通知与权限控制。

## 实操材料

详情页的“实操样例与材料”中可下载每位伙伴的完整讲义。Python报名表样例使用标准库读取CSV，去空编号、按编号保留最后一条记录；两个CSV和脚本放在同一文件夹，编辑器运行后结果写入result。此示例不直接读取xlsx文件。

网页设计与JavaScript样例为完整HTML，下载后可直接在浏览器打开。练习清单不保存数据，刷新清空。Excel样例包含6笔支出，原始总额98元；增加24元后总额122元。

代码、资料与示例身份均用于演示。讲义下载在浏览器本地生成，不向服务器发送个人数据。
